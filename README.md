# 🌐 Internet Playground

Internet Playground is a fun web application where users can explore random content from multiple public APIs in one place. It features a modern, responsive dashboard with interactive cards, a daily curiosity widget, and a persistent favorites system.

## ✨ Features

- 🎲 **Random Fact Card**: Discover useless but interesting facts.
- 🐕 **Dog Image Card**: Fetch random adorable dog photos with download support.
- 🌍 **Country Explorer**: Discover countries with flags, capitals, and maps.
- 🚀 **Space Viewer**: Explore NASA's image archives.
- 💖 **Favorites System**: Save your favorite discoveries (auto-expires in 24 hours).
- 🕒 **Activity History**: Track your last 10 generated items.
- ✨ **Daily Curiosity**: A unique item selected daily for you.
- 🎁 **Surprise Me**: Refresh all cards at once with a single click.
- 🌓 **Dark Mode**: Sleek modern UI with dark/light theme support.
- 🌈 **Animated Gradient**: Premium aesthetic with smooth transitions and glassmorphism.

## 🛠️ Built With

- **React** (Vite)
- **Tailwind CSS**
- **Framer Motion** (Animations)
- **Lucide React** (Icons)
- **Axios** (API Requests)

## 📡 APIs Used

- [Useless Facts API](https://uselessfacts.jsph.pl/)
- [Dog CEO's Dog API](https://dog.ceo/dog-api/)
- [Rest Countries API](https://restcountries.com/)
- [NASA Image and Video Library API](https://images-api.nasa.gov/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/OswaldPhiri/InternetPlayground.git
   cd InternetPlayground
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Deployment

The project is ready to be deployed on **Vercel**:

```bash
npm run build
```
